# Font family names used by lapidary

Font family names used by lapidary

## Usage

``` r
lap_font_families()
```

## Value

A list with `title`, `subtitle`/`body` family names and a logical
`available` flag (whether the families are registered for the current
graphics device; see
[`lap_fonts()`](https://mxnl.github.io/lapidary/reference/lap_fonts.md)).
