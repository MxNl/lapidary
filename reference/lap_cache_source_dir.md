# Path to a source dataset inside the cache

Path to a source dataset inside the cache

## Usage

``` r
lap_cache_source_dir(source, ..., create = FALSE)
```

## Arguments

- source:

  Dataset key, e.g. `"gems-ger"`.

- ...:

  Further path components.

- create:

  Passed to
  [`lap_cache_dir()`](https://mxnl.github.io/lapidary/reference/lap_cache_dir.md).

## Value

A path string.
