# The available time-series indicators

Lists what
[`lap_indicators()`](https://mxnl.github.io/lapidary/reference/lap_indicators.md)
can compute, so you do not have to memorise the `lap_ind_*` function
names.

## Usage

``` r
lap_indicator_registry()
```

## Value

A tibble with one row per indicator: `key` (use it in `.funs`),
`columns` (comma-separated `ind_*` columns it emits), `range` (those
columns' theoretical value ranges in interval notation,
`" | "`-separated and positionally aligned with `columns`),
`needs_date`, `in_all` (whether `.funs = "all"` includes it),
`description` and `reference` (a short citation; the long form is
[`vignette("indicators")`](https://mxnl.github.io/lapidary/articles/indicators.md)).
