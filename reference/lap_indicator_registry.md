# The available time-series indicators

Lists what
[`lap_indicators()`](https://mxnl.github.io/lapidary/reference/lap_indicators.md)
can compute, so you do not have to memorise the `lap_ind_*` function
names.

## Usage

``` r
lap_indicator_registry(long = FALSE)
```

## Arguments

- long:

  If `FALSE` (default) one row per indicator key, with the emitted
  columns, ranges and units `" | "`-separated and positionally aligned.
  If `TRUE`, one row per emitted `ind_*` column (`key`, `column`,
  `range`, `units`, `delta_kind`, `needs_date`, `in_all`, `description`,
  `reference`).

## Value

A tibble. Wide (`long = FALSE`): `key`, `columns`, `range`, `units`,
`needs_date`, `in_all`, `description`, `reference`. Long
(`long = TRUE`): one row per `ind_*` column with `column`, `range`,
`units` and `delta_kind` (how
[`lap_indicator_delta()`](https://mxnl.github.io/lapidary/reference/lap_indicator_delta.md)
differences it). Units are `"m"`, `"months"`, `"weeks"`, `"m/year"`,
`"month"`, `"year"`, ... or `"-"` for a dimensionless quantity (`"m"`
assumes a level column in metres). Value ranges use interval notation;
the long form is
[`vignette("indicators")`](https://mxnl.github.io/lapidary/articles/indicators.md).
