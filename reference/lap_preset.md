# Look up an output preset

Look up an output preset

## Usage

``` r
lap_preset(preset = "web")
```

## Arguments

- preset:

  A name from
  [`lap_preset_names()`](https://mxnl.github.io/lapidary/reference/lap_preset_names.md).

## Value

A list with `width`, `height`, `units`, `dpi`, `base_size`.
