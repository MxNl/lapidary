# Check that an object satisfies the `gwl_wells` contract

Check that an object satisfies the `gwl_wells` contract

## Usage

``` r
check_gwl_wells(x, arg = rlang::caller_arg(x), call = rlang::caller_env())
```

## Arguments

- x:

  Object to check.

- arg:

  Argument name to use in error messages.

- call:

  Calling environment for error messages.

## Value

`TRUE` invisibly on success.
