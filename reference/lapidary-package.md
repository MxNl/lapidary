# lapidary: Data Wrangling, Analysis and Styled Visualisation of German Groundwater-Level Time Series

Tools to ingest, normalise and analyse groundwater-level time series for
Germany (starting with the GEMS-GER benchmark dataset) and to produce a
shared, poster- and web-ready ggplot2 style scheme. The package owns the
data model, caching layer, analysis primitives (reference periods, water
years, per-well summaries, normalisation, trends, spatial hexagon
aggregation) and, from a later milestone, reusable plot builders.
Downstream packages (a Shiny website, a poster builder) consume
lapidary.
