# GEMS-GER sample well metadata

Well locations and static attributes for the wells in
[gems_ger_sample](https://mxnl.github.io/lapidary/reference/gems_ger_sample.md).

## Usage

``` r
gems_ger_wells_sample
```

## Format

A
[gwl_wells](https://mxnl.github.io/lapidary/reference/new_gwl_wells.md)
`sf` layer (EPSG:25832) with `well_id` and curated static attributes
(`surface_elevation`, `well_depth`, `aquifer_medium`, `pressure_state`,
...).

## Source

As
[gems_ger_sample](https://mxnl.github.io/lapidary/reference/gems_ger_sample.md).
