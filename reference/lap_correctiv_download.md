# Download the CORRECTIV groundwater CSVs

Download the CORRECTIV groundwater CSVs

## Usage

``` r
lap_correctiv_download(dir = lap_cache_dir(), overwrite = FALSE, quiet = FALSE)
```

## Arguments

- dir:

  Cache root. Defaults to
  [`lap_cache_dir()`](https://mxnl.github.io/lapidary/reference/lap_cache_dir.md).

- overwrite:

  Force re-download.

- quiet:

  Suppress progress output.

## Value

The directory holding the downloaded CSVs, invisibly.
